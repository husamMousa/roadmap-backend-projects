# roadmap.sh Backend Projects

My solutions to the [roadmap.sh backend projects](https://roadmap.sh/backend/projects).

| Project | Description | Project URL |
| --- | --- | --- |
| [Task Tracker CLI](cli-task-tracker) | Command-line task tracker in plain PHP, stored in a JSON file | https://roadmap.sh/projects/task-tracker |
| [GitHub User Activity](github-user-activity) | CLI that fetches a GitHub user's recent activity from the GitHub API, in plain PHP | https://roadmap.sh/projects/github-user-activity |
| [Expense Tracker](expense-tracker) | CLI expense tracker in plain PHP with categories, monthly budgets and CSV export, stored in a JSON file | https://roadmap.sh/projects/expense-tracker |
| [Number Guessing Game](number-guessing-game) | CLI number guessing game in plain PHP with difficulty levels, hints, a timer and high scores | https://roadmap.sh/projects/number-guessing-game |
| [GitHub Trending CLI](github-trending-cli) | CLI that shows the most-starred new GitHub repositories of the past day, week, month or year, in plain PHP | https://roadmap.sh/projects/github-trending-cli |
| [TMDB CLI Tool](tmdb-cli) | CLI that shows now playing, popular, top-rated and upcoming movies from the TMDB API, in plain PHP | https://roadmap.sh/projects/tmdb-cli |
